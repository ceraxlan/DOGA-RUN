# Third-party notices

Bu repository şu anda üçüncü taraf görsel, model, animasyon, müzik veya ses dosyası içermez.

Unity paketleri Unity Package Manager üzerinden gelir ve kendi lisans/notice dosyalarına tabidir:

| Paket | Sürüm | İlk ekleme gerekçesi |
|---|---:|---|
| Universal Render Pipeline | 17.3.0 | Mobil ölçeklenebilir 3D render pipeline |
| Input System | 1.17.0 | Touch/swipe ve Editor klavye girdisi |
| Cinemachine | 3.1.5 | Takip kamerasının sonraki fazlardaki kompozisyon genişlemesi |
| TextMeshPro | 3.0.9 | Okunabilir Türkçe uGUI metinleri |
| Unity Test Framework | 1.4.6 | EditMode ve PlayMode otomasyonu |

UGS Core, Authentication, Cloud Save ve Leaderboards PHASE 4'ten önce eklenmemiştir; servis yapılandırması yapılmadan gereksiz ağ/paket bağımlılığı yaratılmaması amaçlanmıştır.

Her yeni harici asset eklenmeden önce lisans, kaynak URL'si, sürüm ve kullanım kapsamı bu dosyaya ve `Docs/ASSET_INVENTORY.md` dosyasına yazılmalıdır.
